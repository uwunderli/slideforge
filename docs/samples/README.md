# Lokale Testdateien

Hier können Export-Dateien für manuelle Tests abgelegt werden, z. B.:

- Logos Sermon Builder → **Web page (HTML)**
- `.chs`-Archive zum Set-Import

**Nicht versionieren** — nur für deine Entwicklungsumgebung.  
Beispiel: `logos-sermon-test.html` (falls vorhanden, liegt nur lokal).
