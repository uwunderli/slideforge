# Screenshots für README und GitHub

Lege PNG- oder WebP-Dateien hier ab (ca. 1280–1920 px breit):

| Datei | Inhalt |
|-------|--------|
| `editor.png` | Canvas-Editor mit Folie und Objekten |
| `present.png` | Präsentationsmodus (Steuerung + Folie) |
| `preview.png` | Vorschau oder Export / öffentlicher Link |

Nach dem Hinzufügen in `README.md` verlinken:

```markdown
![Editor](docs/screenshots/editor.png)
```
